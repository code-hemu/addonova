# Internationalization

Addonova uses a custom `.i18n` file format for managing translations, which is compiled to Chrome-compatible `messages.json` during the build.

## .i18n Format

Locale files live in `src/_locales/{locale}.i18n` (e.g., `src/_locales/en.i18n`).

```
# Comments start with #
# This is a comment, it is ignored

@extensionName
My Extension

@extensionDescription
Describes what the extension does

@buttonLabel
Click Me
```

- **Message IDs** start with `@` on their own line
- **Message text** follows on the next non-empty line
- **Comments** start with `#`

## Build Compilation

During `addonova build`, the locales bundler:

1. Reads all `.i18n` files from `src/_locales/`
2. Parses the `@messageId` / text pairs
3. Groups by locale code (filename without extension)
4. Merges multiple files with the same locale code
5. Outputs `_locales/{locale}/messages.json` in Chrome format:

```json
{
  "extensionName": {
    "message": "My Extension"
  },
  "extensionDescription": {
    "message": "Describes what the extension does"
  }
}
```

## Translation Tool

An interactive CLI tool is available for managing translations:

```bash
node node_modules/addonova/src/tools/translate.js
```

### Option 1: Add New Message
1. Enter the English text
2. Choose to auto-generate a message key or provide a custom one
3. The tool translates to all supported locales via Google Translate API
4. Updates all `.i18n` files

### Option 2: Delete Message
Remove a message key from all locales or a specific locale.

The tool uses `translate.googleapis.com/translate_a/single` with a 1-second delay between requests.

## JSON to i18n Conversion

If you have existing `messages.json` files, convert them back to `.i18n` format:

```bash
node node_modules/addonova/src/tools/json2i18n.js
```

## Usage in Extensions

In HTML files, use the `__MSG_` syntax:

```html
<title>__MSG_extensionName__</title>
```

In JavaScript:
```js
chrome.i18n.getMessage('extensionName');
```

In `manifest.json`:
```json
{
  "name": "__MSG_extensionName__",
  "description": "__MSG_extensionDescription__"
}
```
